# هل يمكن أن يكون لنا توأم رقمي؟ — تجربة التحدي

موقع تفاعلي باللغة العربية (RTL) يحوّل العرض التقديمي إلى **خريطة محطات وألعاب وتحديات**، مع نقاط ومستويات وإنجازات. يعتمد على ألوان فاتحة مريحة: الوردي الفاتح والموف واللافندر والأبيض.

## طريقة التشغيل

لا يحتاج المشروع إلى تثبيت. افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا بسيطًا:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## الملفات

| الملف | الوصف |
| --- | --- |
| `index.html` | المحطات التسع، الألعاب، لوحة النتائج، ولوحة الإنجازات |
| `styles.css` | التصميم الفاتح المتجاوب والحركات المختلفة لكل لعبة |
| `script.js` | نظام النقاط والمستويات والإنجازات ومنطق كل الألعاب |
| `README.md` | تعليمات التشغيل وشرح التجربة |

## التجربة الجديدة

- **لا يوجد تنقل بالسابق/التالي.** اختر المحطات من الخريطة الدائرية أسفل الشاشة، أو اضغط الأرقام `1` إلى `9`، أو استخدم زر «ابدأ التحدي» في الغلاف.
- النتائج تظهر فورًا داخل كل لعبة، ولا يُعاد الزائر إلى البداية بعد الفوز.

### الألعاب والتحديات

| المحطة | النوع | التفاعل |
| --- | --- | --- |
| ٢ | اختبار ذكاء | اختر الوصف الأدق للتوأم الرقمي |
| ٣ | لغز تفكير | رتّب خطوات التصنيع بالضغط بالترتيب الصحيح |
| ٤ | محاكاة حيّة | حرّك مؤشرات النوم والخطوات والحالة وسجّل الأنماط ليتعلم التوأم |
| ٥ | لعبة توصيل | اربط كل مجال استخدام بوصفه الصحيح |
| ٦ | اختبار شخصية | اختر العبارة الأدق حول محاكاة الشخصية |
| ٧ | اكتشاف الخطأ | ابحث عن العبارة الخاطئة بين الفوائد والمخاطر |
| ٨ | تحدي سرعة | رتّب السنوات زمنيًا قبل انتهاء المؤقت (٢٠ ثانية) |
| ٩ | لوحة النتائج | ملخص النقاط والمستوى والإنجازات + الخاتمة الأصلية |

### نظام التقدّم

- **النقاط:** تُمنح فور كل إجابة أو تحدٍ ناجح.
- **المستويات:** ٥ مستويات تتصاعد مع النقاط.
- **الإنجازات:** ٦ شارات يمكن عرضها من زر «الإنجازات» أعلى الشاشة.
- **شريط التقدّم:** يُظهر نسبة المحطات المكتملة.

## ملاحظات

- الخط الأساسي `Tajawal` من Google Fonts، مع خطوط بديلة محلية عند غياب الإنترنت.
- يدعم الموقع تفضيل تقليل الحركة `prefers-reduced-motion`.
- تم اختبار التنقل والألعاب على مقاسات كمبيوتر وجوال متعددة دون تمرير رأسي.
